## 已完成修复

- [x] **P1：渲染编辑重写整篇文档，损失未编辑内容。** 基线修改一个段落就改变有序列表起点/缩进，丢失引用定义、链接标题、HTML 折叠块和嵌套代码围栏。现在按顶层块映射原始源码，未修改块逐字保留，包含 CRLF、空文档、制表符和引用定义。HTML 容器块在渲染编辑侧只读，源码侧仍可修改。
- [x] **P1：实际编辑块中的文字可能被误解释为 Markdown。** 对普通文字中的格式符转义；行内代码和代码块按内容选择足够长的反引号围栏，避免嵌套围栏提前结束。保留有序列表起始编号和表格对齐。
- [x] **P1：切换模式/标签销毁源码光标和编辑历史。** 每个文档保留原生编辑器、选区与独立 UndoManager。补上脱离视图再挂载后撤销/重做的模型同步，避免画面已撤销但保存仍写入旧文本。恢复已保存内容时清除未保存标记；不同标签的撤销互不影响。
- [x] **P1：保存静默覆盖外部修改。** 读取/成功保存时记录 SHA-256 内容指纹；保存原文件前验证当前磁盘版本。外部修改、替换或删除会中止保存，保留本地草稿和磁盘版本，提示另存为或重新载入。文件菜单新增“从磁盘重新载入”，仍遵守未保存确认流程。
- [x] **P1：另存为覆盖另一个打开的标签，并产生两份可互相覆盖的模型。** 统一检查文件身份；不同大小写、软链接和硬链接不再绕过同一文件识别。目标属于其他标签时拒绝写入，失败不改变当前路径或脏状态。
- [x] **P2：下划线公式被 Markdown 斜体解析拆开。** 在 Markdown 词法阶段识别数学语法，再渲染 KaTeX；验证 `$x_i+x_j$` 和含下标的分数。代码中的美元符号、转义的价格文本不作为公式解析。
- [x] **P2：预览点击链接会离开正文，无法继续阅读当前文档。** 外部 http/https/mailto 交给默认应用；本地 Markdown 链接进入工作区；同页锚点留在预览；任意应用 URL 协议和本地可执行文件链接被阻止。真实 WebKit 点击测试使用注入的外部打开回调，不启动浏览器。
- [x] **P1：HTML URL 过滤可被控制字符混淆，富文本粘贴也可能带入危险属性。** 按允许的协议过滤 URL，去掉控制字符后判断；移除事件、脚本、活动媒体、富文本危险属性；粘贴只接收纯文本。KaTeX 关闭信任模式。
- [x] **P2：空文档的渲染编辑没有初始化；回写抑制可能吞掉新的源码变化。** 显式跟踪首次加载，回写抑制只匹配完全相同的内容与基址。中文输入组合期间不提交中间文本，结束时通过实际 WKScriptMessage 桥接提交。
- [x] **P1：PDF 横向裁切。** 段落支持长单词换行，表格采用固定布局并允许单元格断行；公式按实际滚动宽度缩放。真实测试曾复现 32 项公式只输出前 8 项；修复后全部 32 项与末项下标保留。超长表格单元格使用唯一字符计数验证完整性，避免相邻列的 PDF 阅读顺序导致错误判断。
- [x] **P2：无界文件输入和无效参数。** 读取前后检查 20 MiB 上限，写入拒绝 NUL/过大文本；非有限导出超时退回安全默认值；字号仍限制 11–26 pt；风格选择没有有效索引时安全回退。
- [x] **测试缺口：原有冒烟断言不能证明可实际使用。** 新增生产代码级回归，执行真实 NSTextView 输入/撤销/重做、标签切换、空白富文本编辑、组合输入事件、WebKit 点击和 PDF 内容核对；关闭/退出的保存、取消、丢弃与保存失败分支通过可注入决策验证。新的编辑、打开和重开窗口会撤销旧的关闭批准标记，避免后续退出绕过未保存检查。

## 可复现验证

```zsh
./scripts/test.sh
./build-app.sh
codesign --verify --deep --strict "$HOME/Library/Caches/MarkdownStudio/Markdown Studio.app"
```

若需要保留 PDF 和快照，请指定空目录；后续同目录重跑依赖测试生成的所有权标记：

```zsh
MARKDOWNSTUDIO_PDF_TEST_OUTPUT=/tmp/markdownstudio-audit ./scripts/test.sh
pdftoppm -f 1 -l 1 -png /tmp/markdownstudio-audit/long.pdf /tmp/markdownstudio-long-first
```

543 是本机通过的检查断言数，不代表代码行覆盖率。原生设置面板实际验证了风格、字号、继续/取消和保存面板衔接；现代系统远程保存面板的最终鼠标确认没有自动化，收到目标 URL 后的生产导出/写入路径已实际运行。中文输入验证使用 WebKit 组合事件，不等同于逐一实测所有系统输入法。

本机已将验证后的 1.5.1（build 7）安装到 `/Applications/Markdown Studio.app`，签名校验通过并成功启动。更新前旧版通过正常退出流程关闭，没有强制结束进程；旧应用包保留在废纸篓的 `MarkdownStudio-before-1.5.1.*` 备份目录中，未删除用户 Markdown 文档。

## 边界与后续约束

- macOS 14 和 Intel 没有实机验证；当前下载构建仍为 Apple Silicon、临时签名、未公证。
- 渲染编辑保留未修改块，实际修改的块会规范化为 Markdown；复杂 HTML 块请在源码编辑，不宣称支持任意 HTML 的无损富文本编辑。
- 过宽公式缩小后可能需要放大 PDF 阅读；复杂长公式推荐用 `aligned` 手动分行。长表格跨页不自动重复表头。
- 保存前冲突检查不等同于跨进程原子比较交换或协作编辑锁；不承诺与不遵守文件协调的并发写入程序实现事务隔离。
- 不把原生视图的 GPU 缓存截图当作 WebKit 渲染结果；网页内容使用 `WKWebView.takeSnapshot` 单独验证。

原生独立撤销管理器的实现参考 [Apple NSTextViewDelegate.undoManager(for:)](https://developer.apple.com/documentation/appkit/nstextviewdelegate/undomanager(for:))，并在本机生产代码集成测试中验证实际行为。
