# 文件打开与使用体验修复记录（v1.4.0）

## 已修复清单

- [x] Finder/系统传入文件只启动程序、不加载正文：接入原生打开 URL 回调，缓存冷启动请求。
- [x] 命令行传入文件未处理：解析启动参数，并忽略系统启动标志。
- [x] 打开面板拒绝 Markdown 类型：补齐导入 UTI、文档声明与扩展名支持。
- [x] 多文件打开覆盖当前内容：独立标签保存各文档状态。
- [x] 重复打开及符号链接路径导致重复文档：规范化路径并切回原标签，保留未保存内容。
- [x] 打开其他文件丢失编辑过的欢迎文档：仅替换未编辑的欢迎页。
- [x] 缺少保存/关闭快捷键：补齐 ⌘S、⇧⌘S、⌘W，保留 ⌘O/⌘N/⌘P。
- [x] 另存为失败却更改文档路径、新建失败仍显示成功：成功写入后才更新状态。
- [x] 同秒新建笔记覆盖旧文件：使用不覆盖写入和递增名称后缀。
- [x] 编码或二进制内容静默损坏：支持 UTF-8、带 BOM 的 UTF-16/UTF-32，拒绝非法文本，保存保留编码。
- [x] 成功提示阻塞接收文件：成功信息移到状态栏，仅错误弹窗。
- [x] 重复外部事件创建多个共享状态的窗口：统一为单编辑窗口、多文档标签。
- [x] 关闭窗口取消后无法恢复文档：在窗口关闭前提示，取消保留窗口；批准关闭后不重复询问。
- [x] 未选中的标签有修改却直接退出：退出时检查所有文档。
- [x] 长文档 PDF 导出卡住、输出持续增长：异步打印并允许独立打印线程，等待字体就绪。
- [x] 设置关闭后主窗口暂时为空导致 PDF 失败：在导出开始前捕获所属窗口。
- [x] PDF 字号标注 pt、实际却使用 px：PDF 样式使用真实 pt 单位。
- [x] 深色 PDF 浅色文字落在白底上：补齐打印背景，正文背景与文字保持可读对比。
- [x] PDF 失败覆盖旧输出：先写临时文件，成功后原子替换；导出显示可取消进度。
- [x] iCloud 同步导致构建卡住/签名失败：缓存和签名产物放在本机 Library/Caches。
- [x] 本机旧进程/旧构建仍接收文件：正常退出旧进程，安装并注册 /Applications 中的新版本。

## 六方面验证

| 方面 | 验证内容与结果 |
| --- | --- |
| 需求完整性 | 覆盖系统打开、应用内打开、启动参数、多文档、保存、关闭和 PDF 导出。保留原有 Markdown、数学公式与渲染编辑能力。 |
| 逻辑正确性 | 所有文件入口共用文件读写层；成功写入后才清除修改状态或更新路径；同文件切换标签，不重载未保存内容。 |
| 边界情况 | 空文档、中文/空格路径、大小写扩展名、BOM 编码、非法文本、目录、缺失文件、不可写路径、新建重名、符号链接、混合有效/无效输入。 |
| 代码质量 | 文件读写集中到 MarkdownFileIO；UI 状态使用主线程隔离；导出任务结束释放引用与临时文件；源码构建无编译警告，plist 与差异格式检查通过。 |
| 测试覆盖 | 30 项真实文件读写检查、25 项真实文档模型检查通过，另有 GFM、KaTeX、编辑桥接、快捷键与应用元数据冒烟检查。模型测试直接编译生产代码，不使用另一套模拟实现。 |
| 实际运行 | 在本机 macOS 26.5.2 / Apple Silicon 上验证冷启动、运行中打开、多文件标签、⌘O、⌘S 落盘、重复打开未保存文件、关闭取消、后台脏标签退出提示及 PDF 设置控件。长文导出为 23 页 A4，65 节和首尾标记完整，首/中/末页视觉检查通过。深色 PDF 也完成视觉检查。 |

物理拖拽入口已经实现并编译检查，但本次没有完成跨窗口的实际拖拽测试；macOS 14 和 Intel 硬件未实机验证。不同字号与风格的 PDF 页数会变化。

## 复现验证

```zsh
./scripts/test.sh
./build-app.sh
open -a "/Applications/Markdown Studio.app" "Tests/Fixtures/中文 打开测试.md"
open -a "/Applications/Markdown Studio.app" "Tests/Fixtures/pdf-long.md"
```

在长文档中按 ⌘P，选择“书籍衬线”、22 pt 并导出，再检查完整性：

```zsh
swift Tests/VerifyExportedPDF.swift /absolute/path/to/pdf-long.pdf
```

PDF 文本检查不代替视觉检查。发布前另渲染首、中、末页确认表格、中文与公式没有遮挡或缺失。
