# v1.6 PDF 排版与实际预览

按 `⌘P` 打开“PDF 导出设置与预览”。左侧为打印参数，右侧直接展示实际生成的 PDF；没有使用不同排版规则的网页缩略图。

## 设置

| 设置 | 选项 |
| --- | --- |
| 风格 / 字体 | 白纸无衬线、白纸衬线、墨黑无衬线、墨黑衬线 |
| 正文字号 | 8–32 pt，默认 16 pt |
| 主标题字号 | Markdown `#` / H1：16–72 pt，默认 32 pt |
| 行距 | 紧凑 1.4、标准 1.65、宽松 1.9 |
| 纸张 / 方向 | A4、Letter；纵向、横向 |
| 上、下、左右边距 | 分别选择小 12 mm、中 20 mm、大 28 mm |
| 页眉 / 页脚 | 可独立启用文档名页眉、`第 n / N 页` 页脚 |
| 页眉页脚字号 | 小 8 pt、中 10 pt、大 12 pt |

“上边距 / 页眉”“下边距 / 页脚”调整的是留白，包括页眉页脚区域，不会改变正文或页眉的字号。H1 字号仅作用于一级标题，页眉的文档名使用独立的页眉页脚字号。文档名只显示文件名，不包含完整路径；过长时截断为省略号。墨黑风格包含深色页面背景，纸质打印建议使用白纸风格。

预览支持翻页、缩放与适合页面，显示总页数。面板可调整尺寸，较矮窗口的设置区可以滚动。修改设置后等待约 250 ms 再开始生成，以免拖动滑块时连续产生无用任务；旧任务取消、旧预览变淡，生成完成前不能点击“继续”。

点击“继续”后才记住设置，然后选择保存位置。最终写入的是预览的同一份 PDF 数据，保证纸张、分页、边距、字号与预览一致。取消设置面板不写入偏好；“恢复默认设置”也需继续确认才会记住。保存面板取消后保留已确认的偏好，不创建文件。

旧版设置会迁移：简洁白纸 → 白纸无衬线，暖色纸张 / 书籍衬线 → 白纸衬线，夜间墨黑 → 墨黑无衬线；旧正文大小会保留在新范围内。

## 实现与验证

- `PDFExportOptions.swift` 负责参数、归一化和偏好迁移；`PDFExportOptionsPanel.swift` 使用原生 AppKit 控件与 PDFKit 预览。
- `PDFExporter.render` 在内存中生成 PDF，预览不创建临时文件，也不请求保存路径。导出复用同一分页/绘制引擎，可直接保存经过验证的预览数据。
- WebKit 按打印内容宽度排版，分页根据纸张方向及实际边距计算。正文、页眉和页脚分开绘制，保持矢量文字、公式和链接。
- 回归测试覆盖全部四种风格、纸张/方向与上下边距组合、真实 PDF 字号和坐标、每页文档名和页码、关闭页眉页脚、快速改动后的旧预览失效、取消、恢复默认、偏好保存和逐字节导出一致性。
- 使用真实 NSPanel、NSSlider、NSPopUpButton、PDFView 与 WebKit；另用 Poppler 渲染页面检查版面。原生控件缓存截图可能不能完整反映系统半透明材质与 GPU 控件，PDF 页面的核验以实际 PDF 渲染为准。

2026-10-24 在本机 Apple Silicon / macOS 26.5.2 上通过 735 项检查：文件 38、文档/参数/几何 151、PDF/原生面板/预览 511、编辑器 35。65 节长文实际生成 23 页；另外验证四种纸张/方向组合、6 页 Letter 横版的每页页眉页码，以及正文 14 pt 与 H1 46 pt 的真实 PDF 字号。小边距/标准行距的同一份测试正文为 7 页，大边距/宽松行距为 14 页，首尾均完整。

运行：

```zsh
MARKDOWNSTUDIO_PDF_TEST_OUTPUT=/tmp/markdownstudio-layout-qa ./scripts/test.sh
```

首次使用空目录，后续依赖测试生成的所有权标记。测试不会改写用户文档，预览不写入下载目录。系统远程保存对话框的最终鼠标确认未自动化，收到目标 URL 后的真实写入路径已验证；打印效果还取决于打印机的硬件边距与驱动设置，未做实体打印机测试。
