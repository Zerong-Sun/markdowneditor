# Markdown Studio v1.5.1

本次发布对应六方面质量审计后的修复版，应用版本为 1.5.1（build 7）。

## 修复与改进

- 渲染编辑按块回写，保留未修改块的原文、引用定义、列表编号和嵌套代码围栏；HTML 容器块在渲染侧只读，可在源码侧编辑。
- 修复下划线公式、空文档初始化、中文组合输入和源码/渲染回写同步。
- 切换模式和标签保留源码光标与独立撤销历史；撤销/重做同步正文与未保存状态。
- 增加外部修改/删除冲突保护与“从磁盘重新载入”；防止另存为覆盖其他已打开标签，识别大小写路径、软链接和硬链接。
- 网页链接在默认浏览器打开，Markdown 链接在工作区打开，不再带走当前预览；加强 HTML 和 URL 过滤。
- 修复 PDF 超长单词、表格单元格和宽公式裁切；保留三种显示模式、⌘P 设置/保存面板、四种风格和 11–26 pt 字号。
- 补齐关闭/退出、大文件、无效参数和失败恢复的回归测试。

## 验证

在本机 Apple Silicon、macOS 26.5.2、Swift 6.2.4 上通过 543 项检查（文件 38、文档/策略 71、PDF/面板/模式 399、编辑器 35）。65 节长文实际导出为 23 页 A4，四种风格、80 行表格、90 行代码与 32 项宽公式完整。

原生设置面板的风格、字号、继续/取消和保存面板衔接已测试；系统远程保存面板最终鼠标确认未自动化。中文输入使用 WebKit 组合事件验证，不等同于实测所有输入法。详见[完整审计与修复清单](https://github.com/Zerong-Sun/markdowneditor/blob/v1.5.1/docs/QUALITY_AUDIT.md)。

## 下载与安装

下载附件 `Markdown-Studio-macOS.zip`，解压后将 `Markdown Studio.app` 放到“应用程序”文件夹。ZIP 内含安装说明和第三方声明。升级前请保存文档并正常退出旧版，替换应用包不会要求删除文档。

预编译包为 Apple Silicon，要求 macOS 14 或以上；Intel Mac 可从源码构建，Intel 和 macOS 14 未实机验证。此包使用临时签名，未经过 Apple 公证。请核对来源和附件 `SHA256SUMS.txt`；若系统阻止打开，按 [Apple 安全打开指引](https://support.apple.com/zh-cn/102445)确认，不要关闭系统安全保护。

```zsh
shasum -a 256 -c SHA256SUMS.txt
```

## 已知限制

单文件 20 MiB、PDF 最多 1000 页；过宽公式会缩小，复杂公式建议手动分行；长表格跨页不自动重复表头。渲染编辑会规范化实际修改块，复杂 HTML 请使用源码编辑。Mermaid、脚注等示例扩展不提供专用渲染。
