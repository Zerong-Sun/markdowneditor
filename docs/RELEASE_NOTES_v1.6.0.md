# Markdown Studio v1.6.0

应用版本 1.6.0（build 8）。本次升级 PDF 排版与打印设置，加入实际 PDF 预览。

## 新功能与改进

- 四种风格：白纸无衬线、白纸衬线、墨黑无衬线、墨黑衬线。旧版风格和正文大小自动迁移。
- 正文 8–32 pt、一级标题 16–72 pt 可独立设置；新增紧凑、标准、宽松三档行距。
- 上、下、左右打印边距分别提供小 12 mm、中 20 mm、大 28 mm，支持 A4 / Letter 和纵向 / 横向。
- 可独立启用文档名页眉和“第 n / N 页”页脚，页眉页脚字号另选小 8 pt、中 10 pt、大 12 pt。文档名不包含完整路径，过长时省略。
- 原生设置面板右侧显示实际 PDF，支持翻页、缩放、适合页面和页数显示；面板可以调整尺寸，左侧设置可以滚动。
- 调整设置后自动更新预览并取消旧任务，准备完成前禁用“继续”，防止保存过期结果。最终保存预览的同一份 PDF 数据，不会再次排版。
- 提供恢复默认和设置记忆；取消设置不修改已保存的偏好。预览仅在内存生成，不在下载目录创建临时文件。

按 `⌘P` → 调整左侧参数 → 检查右侧预览 → 点击“继续” → 选择保存位置。边距控制留白，页眉页脚字号控制文字大小；纸质打印通常建议选择白纸风格，墨黑风格会打印深色背景。

## 下载与安装

下载附件 `Markdown-Studio-macOS.zip`，解压后将 `Markdown Studio.app` 拖到“应用程序”文件夹。ZIP 附有安装说明和第三方声明。升级前请保存文档并正常退出旧版，替换应用包即可，不需要删除 Markdown 文档。

预编译包适用于 Apple Silicon（M 系列），要求 macOS 14 或以上；Intel Mac 可从源码构建。应用使用本地临时签名，未经过 Apple 公证。请核对下载来源和附件 `SHA256SUMS.txt`；若系统阻止打开，按 [Apple 安全打开指引](https://support.apple.com/zh-cn/102445)确认，不要关闭系统安全保护。

将 ZIP 和校验文件放在同一目录后运行：

```zsh
shasum -a 256 -c SHA256SUMS.txt
```

应显示 `Markdown-Studio-macOS.zip: OK`。

## 已知限制

单个文本文件最多 20 MiB，PDF 最多 1000 页；过宽公式会缩小，复杂公式建议用 `aligned` 手动分行；长表格跨页不自动重复表头。渲染编辑会规范化实际修改块，复杂 HTML 请使用源码编辑。Mermaid、脚注等示例扩展不提供专用渲染。
